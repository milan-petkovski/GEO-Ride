About GEO Ride: 3D World Driving Simulator

GEO Ride is a 3D driving simulator built for the modern web using Mapbox GL JS and Three.js. Drive a Car, Truck, Bus or God Mode vehicle anywhere on Earth using real satellite maps.

  • Car, Truck and Bus with individual physics models
  • 4 map styles: Satellite, Hybrid, 3D Buildings, 2D Streets
  • Real-time multiplayer via MQTT WebSockets
  • Location search and cinematic teleport
  • Mobile PWA with gyroscope steering
